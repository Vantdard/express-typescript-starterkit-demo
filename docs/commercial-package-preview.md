# Commercial Package Preview

The full VS Code Project StarterKit V1 is distributed as a private commercial ZIP package.

## Included In The Commercial Version

- Complete Express + TypeScript StarterKit source code.
- Core app/server/router foundation.
- Typed and validated environment configuration.
- Logging foundation.
- Core middleware.
- Global error handling.
- Request validation.
- Health endpoint.
- Complete Users reference module.
- Full buyer onboarding documentation.
- Project structure documentation.
- Test suite.
- Tooling configuration.
- Commercial license.

## Excluded From The Commercial ZIP

- Git history.
- `node_modules/`.
- Build output.
- Coverage output.
- Local `.env` files.
- Internal strategy documents.
- Internal release staging folders.
- Temporary development artifacts.

## Why This Public Repo Is Smaller

This audit demo is designed to prove quality without redistributing the complete paid product. The commercial version contains additional implementation examples and buyer-facing documentation intended for customers.
