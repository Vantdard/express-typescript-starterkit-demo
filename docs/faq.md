# FAQ

## Is this the full product?

No. This repository is a public audit demo. It includes real runnable code, but it intentionally excludes premium parts of the commercial StarterKit.

## Can I run this repository?

Yes. It supports `npm install`, `npm run lint`, `npm run test`, `npm run build`, `npm audit` and `npm run dev`.

## Why is the Users module not included?

The complete Users module is part of the commercial package. It serves as the reference application module for buyers and demonstrates the full module pattern.

## Does the commercial version include authentication or a database?

No. V1 is intentionally a clean engineering foundation. It does not include authentication, authorization, JWT, Prisma, Docker, Swagger or database integrations.

## Who is the commercial StarterKit for?

It is for developers who want a clean Express + TypeScript backend foundation without spending the first hours wiring configuration, middleware, validation, error handling, tests and documentation.

## Can buyers modify the code?

Yes. The product is designed to preserve developer ownership. Buyers should be able to understand, modify and replace the foundation as needed within the terms of the commercial license.
